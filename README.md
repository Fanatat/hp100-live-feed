# Показания домашнего датчика воздуха HP100

Публичный JSON-фид: CO₂, температура, влажность, PM2.5 и история показаний.
Схема: датчик → локальный сервер → публикация JSON в GitHub →
[виджет сайта](http://vanatat.ru/).

## Получить данные

- [latest.json](https://raw.githubusercontent.com/Fanatat/hp100-live-feed/master/latest.json) — последнее опубликованное показание.
- [history.json](https://raw.githubusercontent.com/Fanatat/hp100-live-feed/master/history.json) — история источника за 24 часа.

Пример формата (числа демонстрационные):

```json
{"co2":650,"temperature":23.1,"humidity":45,"dust":4,"updated":"2026-09-28T09:00:00+00:00"}
```

| Поле | Значение и единица | Пропуски |
|---|---|---|
| `co2` | Концентрация CO₂, ppm | latest: поле может отсутствовать; history: `null` |
| `temperature` | Температура, °C | То же |
| `humidity` | Относительная влажность, % | То же |
| `dust` | Концентрация PM2.5, мкг/м³ (`pm25` источника) | То же |
| `updated` | ISO 8601, UTC; время публикации latest | Всегда добавляется скриптом |
| `timestamp` | Время точки источника в history | Переносится с сервера, может быть `null` |

`updated` не является временем физического измерения: скрипт создаёт новую метку
при каждом успешном опросе. Потребитель должен проверять её возраст, пропуски
полей и историю. Свежая публикация сама по себе не доказывает свежесть датчика.
Номинальная история — около 96 точек с шагом 15 минут за 24 часа; скрипт переносит
ответ сервера, не гарантирует длину и не заполняет пропуски.

## Публикация

[update_feed.py](update_feed.py) опрашивает локальный сервер на порту 8080,
формирует JSON и выполняет commit + push. В режиме `--loop` пауза 300 секунд
идёт после завершения цикла, поэтому это целевой интервал, а не точное расписание.
Коммит пропускается только когда файлы не изменились; новая метка `updated`
обычно меняет файл даже при одинаковых числах.

Нужны Python 3, Git, локальный сервер датчика и доступ к push.
[hp100-feed.service](hp100-feed.service) содержит шаблон systemd и инструкции.
Разовый `python3 update_feed.py` также выполняет публикацию; для простого чтения
используйте JSON-ссылки выше. Клонирование фида не подключает домашний датчик.
